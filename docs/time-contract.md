# Контракт времени

Все Unix timestamp-поля API и базы данных передаются и хранятся в миллисекундах
с начала Unix epoch в UTC. Это относится к `created_at`, `updated_at`,
`signed_at`, `expires_at`, датам отпусков, сменных отчётов и графиков.

Параметры фильтров для этих полей используют тот же формат. Поля SQL-типа
`DateTime` (например, `logs.timestamp`) этим контрактом не затрагиваются.

Миграция `20260804_epoch_milliseconds` переводит исторические значения,
которые выглядят как Unix seconds, умножением на `1000`, и обновляет серверные
значения по умолчанию. Значения, уже находящиеся в миллисекундах, не меняются.
