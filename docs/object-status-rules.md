# Статусы объектов

Доступные значения статуса объекта передаются фронтенду через
`GET /objects/statuses` в формате `{value, label}`:

| `value` | `label` |
|---|---|
| `waiting` | `В Ожидании` |
| `active` | `Действующий` |
| `completed` | `Завершенный` |

Endpoint доступен по JWT или API-ключу с назначенным правом
`objects-statuses` (`GET /objects/statuses`). Право добавляется в справочник
при старте приложения; существующим ключам его нужно назначить явно.

Объект можно перевести в `completed` только если все его неудалённые
спецификации находятся в статусе `closed`.
