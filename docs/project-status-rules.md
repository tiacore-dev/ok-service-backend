# Статусы спецификаций (`project`)

В сервисе сущность `project` является спецификацией. Спецификация хранит поле
`status` и создаётся со статусом `pending` (`На согласовании`).

## Enum для фронтенда

Технические значения статусов:

| `value` | `label` |
|---|---|
| `pending` | `На согласовании` |
| `in_progress` | `В работе` |
| `works_completed` | `Работы выполнены` |
| `closed` | `Закрыто` |

Получить значения можно через `GET /projects/statuses`. Ответ содержит массив
`statuses` с полями `value` и `label`.

## Изменение статуса

Статус изменяется только отдельной командой:

`PATCH /projects/{project_id}/status`

```json
{"status": "in_progress"}
```

Операция доступна ролям `admin` и `manager`. Основной endpoint редактирования
спецификации (`PATCH /projects/{project_id}/edit`) статус не изменяет.

Разрешены переходы только между соседними статусами в следующем порядке:

`pending ↔ in_progress ↔ works_completed ↔ closed`.

Повторная установка текущего статуса допускается. Переход через статус или
перескок через несколько статусов отклоняется.

Перевод в `closed` (`Закрыто`) разрешён только если у всех `project_works`
данной спецификации поле `signed` имеет значение `true`. Проверка выполняется
в одной транзакции с изменением статуса и блокировкой соответствующих работ.

## Смены и объекты

Создание сменного отчёта для спецификации разрешено только при статусе
`in_progress` (`В работе`).

Статус объекта `completed` (`Завершенный`) можно установить только если все его
неудалённые спецификации имеют статус `closed` (`Закрыто`).
