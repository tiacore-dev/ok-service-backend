# Массовое создание смен

`POST /shift_reports/add-bulk` принимает те же общие поля, что
`POST /shift_reports/add`, но вместо поля `user` принимает обязательный
непустой массив UUID `user_ids`.

```json
{
  "user_ids": ["11111111-1111-4111-8111-111111111111", "22222222-2222-4222-8222-222222222222"],
  "date": 1792515600000,
  "project": "33333333-3333-4333-8333-333333333333",
  "night_shift": false,
  "comment": "Общая смена"
}
```

Все остальные поля и вложенный список `details` общие: каждому уникальному
пользователю создаётся отдельная смена с отдельными деталями и расходом
материалов. Суммы рассчитываются существующим алгоритмом для каждого
сотрудника. Даты передаются в Unix milliseconds; правила nullable-полей и
значения по умолчанию совпадают с одиночным созданием.

Пустой, отсутствующий или некорректный `user_ids` отклоняется с `400`.
Повторные UUID пропускаются, включая разные регистры записи одного UUID.
Порядок результата соответствует первому появлению пользователя в массиве.
Проверяется существование всех пользователей, спецификации и ссылок деталей.

Весь запрос выполняется в одной транзакции: любая ошибка при создании смены,
деталей или расхода материалов отменяет создание всех записей запроса.
Проверка отсутствия сотрудника и проверка статуса спецификации `in_progress`
сохраняются; такие конфликты возвращают `409`. Пересчёт статистики выполняется
после успешной фиксации всех смен.

Права совпадают с одиночным созданием: роль `user` не может создавать смены
(`403`); передавать `short_shift` могут только `admin`, `manager` и
`project-leader`. `created_by` у всех созданных записей — текущий пользователь.

Для API-ключа требуется отдельное право `shift-reports-create-bulk` с точным
маршрутом `POST /shift_reports/add-bulk`. Bootstrap добавляет его в справочник
при старте; существующим ключам право назначается явно.

Успешный ответ (`200`):

```json
{
  "msg": "New shift reports added successfully",
  "shift_report_ids": ["44444444-4444-4444-8444-444444444444", "55555555-5555-4555-8555-555555555555"]
}
```

Новый метод не требует миграций или новых настроек окружения.
