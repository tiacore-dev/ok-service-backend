# Стандарты смены

Справочник `shift_standards` поддерживает создание (`POST /add`), частичное
редактирование (`PATCH /{id}/edit`), чтение (`GET /{id}/view`, `GET /all`)
и удаление (`DELETE /{id}/delete/hard`) под префиксом `/shift_standards`.
Чтение требует аутентификации; изменения доступны администратору или API-ключу
с правом на соответствующий маршрут.

`category` — обязательное уникальное целое число; `standard` — обязательное
конечное число строго больше нуля. `notification_text` — необязательный текст,
допускающий `null`.

Согласованные 21.10.2026 дополнительные поля:

- `production_rate_rub` — норма выработки в рублях, необязательный Float,
  конечное число `>= 0` или `null`.
- `penalty_rate_percent` — процент штрафа за невыполнение, необязательный Float,
  конечное число от `0` до `100` включительно или `null`.

При создании пропущенные новые поля сохраняются как `NULL`. При редактировании
пропущенное поле сохраняет прежнее значение, явный `null` очищает его;
ноль сохраняется как число. Оба поля возвращаются в просмотре и списке,
включая значения `null`. Некорректные значения возвращают HTTP 400.
Новые фильтры не добавляются.

Миграция `20261021120000` добавляет nullable-колонки Float без значений по
умолчанию и заполнения существующих записей, а также CHECK-ограничения
диапазонов. Для `production_rate_rub` проверяется
`production_rate_rub >= 0 AND production_rate_rub < 'Infinity'::double precision`,
что запрещает `NaN` и обе бесконечности при прямой записи в PostgreSQL,
сохраняя возможность записать `NULL` и любое конечное неотрицательное Float.
После применения у старых записей оба поля равны `NULL`.
Откат удаляет ограничения и новые колонки вместе с их значениями.
Настройки окружения не меняются. Эти поля хранят параметры справочника;
автоматическое применение штрафов и изменение расчётов смен в задачу не входят.
